# Resources

A collection of resources I use to study and understand Operating Systems.

The resources are organized around the topics covered in this repository and include lectures, documentation, articles, books, visual explanations, and practice material.

---

## 📚 Primary Resources

These are the main resources used for studying the concepts in this repository.

### 1. Operating System Concepts

**Book:** *Operating System Concepts*  
**Authors:** Abraham Silberschatz, Peter Baer Galvin, Greg Gagne

A comprehensive textbook covering the fundamental concepts of Operating Systems, including processes, threads, scheduling, synchronization, deadlocks, memory management, storage management, and security.

**Useful for:**

- Understanding OS fundamentals
- Process management
- CPU scheduling
- Process synchronization
- Deadlocks
- Memory management
- Virtual memory
- File systems
- Security

# 🛠️ Practice Resources

Understanding Operating Systems requires more than memorizing definitions.

Try implementing or experimenting with simple programs related to:

- Process creation
- Threads
- CPU scheduling
- Inter-Process Communication
- Synchronization
- File operations
- Memory concepts
- Linux process management
- Linux file permissions

Python can be used for many simulations, while C/C++ can be useful for understanding lower-level OS concepts.
